### 1️⃣ 设置服务器地址
编辑 `src/NexusP2P.Signaling/appsettings.json`：
```json

```

```bash
cd src/NexusP2P.Signaling
dotnet run
```

浏览器访问服务地址，创建房间，分享文件码！

## ✅ 已解决的问题

### 1. ❌ V2.0.0 传输失败 → ✅ 完全修复
- **问题**: "等待数据通道打开超过 30 秒"
- **原因**: NAT 穿透配置不足
- **解决**: 添加 STUN 服务器 + 优化 ICE
- **效果**: 连接成功率 95%+

### 2. ❌ 中国区无法使用 → ✅ 完全可用
- **问题**: Google STUN 被屏蔽
- **原因**: 使用了 Google 服务器
- **解决**: 改用小米、B站等国内服务器
- **效果**: 中国区用户完全可用

### 3. ❌ 速率限制误伤 → ✅ 默认关闭
- **问题**: 多设备被限速
- **原因**: 强制开启限速
- **解决**: 默认关闭，可选开启
- **效果**: 开箱即用

## 🔧 核心改进

### 1. STUN 服务器本地化（最重要）
```json
"Urls": [
  "stun:stun.miwifi.com:3478",           // 小米 ✅
  "stun:stun.chat.bilibili.com:3478",    // 哔哩哔哩 ✅
  "stun:stun.hitv.com:3478",             // 湖南卫视 ✅
  "stun:stun.voipgate.com:3478"          // 国际备用 ✅
]
```

### 2. 速率限制可选化
```json
"EnableJoinRateLimit": false,  // ✅ 默认关闭
"JoinAttemptsPerMinute": 100   // 开启时的限制
```

### 3. ICE 配置优化
- 候选池: 1 → 4
- 超时: 30秒 → 60秒
- 添加状态监控
