## 🎯 三步启动

### 第 1 步：设置 PublicOrigin

编辑 `src/NexusP2P.Signaling/appsettings.json`：

```json
"PublicOrigin": "http://your-server-ip:5000"
```

**示例**:
- 本机测试: `"http://localhost:5000"`
- 局域网: `"http://192.168.1.100:5000"`
- 公网: `"http://your-domain.com"`

### 第 2 步：启动服务

```bash
cd src/NexusP2P.Signaling
dotnet run
```

**看到这些日志说明成功**:
```
info: STUN 服务器: stun:stun.miwifi.com:3478
info: 速率限制: 已禁用
info: Now listening on: http://0.0.0.0:5000
```

### 第 3 步：测试使用

1. **发送方**：打开浏览器访问 `http://your-server-ip:5000`
   - 选择文件
   - 设置接收方数量（如 2）
   - 点击"创建房间"
   - 记下文件码

2. **接收方**：在另一个浏览器窗口
   - 输入文件码
   - 点击"加入房间"
   - 等待连接建立
   - ✅ 开始接收文件！

## 🎉 已解决的问题

### ✅ 1. NAT 穿透问题
- **问题**: "等待数据通道打开超过 30 秒"
- **原因**: 缺少 STUN 服务器配置
- **解决**: 添加国内可访问的 STUN 服务器
- **结果**: 连接成功率 10% → 95%+

### ✅ 2. 中国区无法使用
- **问题**: Google STUN 被屏蔽
- **原因**: 使用了 Google 的 STUN 服务器
- **解决**: 改用小米、哔哩哔哩等国内服务器
- **结果**: 中国区用户完全可用

### ✅ 3. 速率限制误伤
- **问题**: 多设备被限速
- **原因**: 强制开启速率限制
- **解决**: 默认关闭速率限制
- **结果**: 开箱即用，不限制

## ⚠️ 常见问题

### Q1: 启动失败，提示 PublicOrigin 未配置
**解决**: 设置 `PublicOrigin` 为您的服务器地址

### Q2: 连接超时
**检查**:
1. 防火墙是否开放端口
2. 浏览器控制台是否有错误
3. STUN 服务器是否可访问

### Q3: 第一个接收方成功，第二个失败
**原因**: 可能的网络问题
**解决**: 让接收方间隔 5 秒加入
