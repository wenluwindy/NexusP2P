## 🎯 打包后的配置

### 生产环境默认配置

打包后的 `appsettings.json` 默认配置：

```json
{
  "Signaling": {
    "PublicOrigin": "https://p2p.你的域名",  // ⚠️ 必须修改
    "EnableJoinRateLimit": true,             // ✅ 生产环境默认开启
    "JoinAttemptsPerMinute": 100,            // ✅ V2.0.0 已提高
    "MaxReceiversPerRoom": 2147483647,       // ✅ 不限制
    "Turn": {
      "Urls": [
        "stun:stun.miwifi.com:3478",         // ✅ 国内可用
        "stun:stun.chat.bilibili.com:3478",
        "stun:stun.hitv.com:3478",
        "stun:stun.voipgate.com:3478"
      ]
    }
  }
}
```

### 部署时需要修改

**必须修改**:
- `PublicOrigin` - 设置为实际域名

**可选修改**:
- `EnableJoinRateLimit` - 内网可设为 `false`
- `Turn.Urls` - 海外可改用 Google STUN
